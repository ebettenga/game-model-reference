API docs by Redocly

Game Data API (1.0.0)

Download OpenAPI specification:

A game-agnostic, read-only API for publishing the static data of an RPG/MMO: classes, items, skills, creatures, NPCs, quests, zones, dungeons, crafting and more.

Conventions

  • Every collection follows the same three-call pattern: GET /{collection} returns all IDs, GET /{collection}/{id} returns one record, GET /{collection}/batch?ids=1,2,3 returns several.
  • Values a game defines for itself (stats, elements, rarities, item categories, currencies) are not hard-coded enums. They are lookup keys served from /lookups/*.
  • Display text is a LocalizedText map of language code to string. Pass ?lang=en to receive only that language.
  • Clients should cache everything and refetch only when GET /version changes.
